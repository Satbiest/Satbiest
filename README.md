## 👨‍💻 About Me

Saya adalah praktisi data yang bersemangat mengubah **data mentah** menjadi **wawasan bisnis berdampak tinggi** dan **model prediktif yang akurat**. Saya bekerja di tiga pilar yang saling melengkapi: **Data Analytics** untuk memahami apa yang terjadi, **Data Science** untuk memprediksi apa yang akan terjadi, dan **Business Intelligence** untuk mengomunikasikannya secara jelas kepada pengambil keputusan.

- 🔭 **Fokus saat ini:** Financial Early Warning System (EWS) berbasis Deep Learning (LSTM, Hybrid CNN-LSTM, GRU) dan Automated Data Pipeline untuk dashboard near real-time
- 📊 **Pengalaman:** Business Analyst, Data Scientist, dan Data Analyst Intern di sektor asuransi, telekomunikasi, dan teknologi
- 🧠 **Sedang mendalami:** Time Series Forecasting, Hyperparameter Optimization, dan Model Deployment
- ⚙️ **Sedang membangun:** Pipeline otomatis dari Excel di SharePoint ke Power BI melalui Power Automate
- 🤝 **Terbuka untuk:** Kolaborasi, proyek open-source, dan peluang karier di bidang data
- 💬 **Tanyakan kepada saya tentang:** Analisis data, pemodelan deret waktu, desain dashboard, dan data storytelling
